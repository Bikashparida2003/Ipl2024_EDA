# 2024-IPL-Exploratory-Data-Analysis (Using python-Numpy-Pandas)

## Project Objective
Analysing 2024 IPL Data and finding Valueable insights.

## Dataset used
- <a href="https://github.com/Bikashparida2003/Ipl2024_EDA/blob/main/ipl_data.csv">Dataset</a>

## Questions
- In 2024 IPL which players got most man of the match?
- Which teams Won highest no of matches?
- Find top five teams won after batting first?
- Find top five teams won after batting second or bowling first?
- Find the teams who had won the toss also won the match?

## Process
- Verify data for any missing values and anomalies In excel.
- made sure data is consistent and clean with respect to data type and value used.
- Import CSV File to Jupyter Notebook
- Visualizing Data using Pandas, Matplotlib and Seaborn
